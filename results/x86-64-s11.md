# X86-64-S11 — the system layer (what landed, and what is a NAMED GAP)

**Unit:** `HANDOFF=v86c-x86-64-s11`, slice **S11** of `results/x86-64-plan.md` (§6's S11 row; §2.2
the per-item table; §5.2-5.3). S0-S10 are landed; S12-S13 untouched.

**The claim, one sentence:** the walk now **composes 1 GiB and 2 MiB pages**, **rejects
non-canonical linear addresses with the `#GP` hardware takes** (closing the defect S5 recorded), and
the **FS/GS/KERNEL_GS bases and the SYSCALL MSRs are modelled and round-trip** — each with a
mutation probe that fails before the change — while **SYSCALL/SYSRET, SWAPGS, the 64-bit
GDT/IDT/TSS/IST and the interrupt frame are NAMED GAPS**, not promises.

The shipped binary moved `bb47de47…` (S10) to **`021c0929…`** (MEASURED).

## 1. What landed

### 1.1 The walk: 1 GiB, 2 MiB, and the physical bound on both

`paging.c:do_page_walk64` composed only 4 KiB pages in S5 (the two larger sizes were **named
stops**). S11 composes them: `PDPTE.PS` → a **1 GiB** page (frame bits 51:30, offset 29:0),
`PDE.PS` → a **2 MiB** page (frame 51:21, offset 20:0), each with its own RW/US/NX/GLOBAL bits, its
own A/D update on the entry that carries them, and the **32-bit physical bound** still applied to
the frame (`plan §5.1`: a frame at or above 4 GiB stops by name rather than truncating).

### 1.2 Canonicality: `#GP`, and the alias S5 recorded is gone

The four index masks take `(addr >> 39/30/21/12) & 0x1FF`, so a non-canonical address is **aliased
onto its low 48 bits** — and in an identity-mapped machine that alias is a **mapped page**, i.e. a
successful translation to the wrong-but-real page instead of a fault. S5 recorded that as a defect;
S11 checks bits 63:48 against bit 47 **at the walk's entry** and raises **`#GP(0)`** (the SDM's
exception for a non-canonical linear address — *not* `#PF`).

### 1.3 The MSR set: FS/GS/KERNEL_GS bases and the SYSCALL registers

`wrmsr`/`rdmsr` now handle `MSR_FS_BASE` (0xC0000100), `MSR_GS_BASE` (0xC0000101),
`MSR_KERNEL_GS_BASE` (0xC0000102), `MSR_STAR`, `MSR_LSTAR`, `MSR_FMASK`. The FS/GS bases write
**`segment_offsets[FS/GS]`** — the slots S3 widened for exactly this, i.e. the base the address
generator already reads, so a guest's `mov rax, fs:[0]` follows the MSR. **A pre-existing defect is
fixed on the way**: the port's old `IA32_KERNEL_GS_BASE` placeholder was defined as **0xC0000101**
(GS_BASE's number), so it was a no-op on the wrong register.

**A register that round-trips is not an instruction that works** — `STAR`/`LSTAR`/`FMASK` are
stored and read back so the SYSCALL seat exists, and the SYSCALL/SYSRET **encodings** are §3's gap.

## 2. The gate, one mutation probe per landed rule

`tests/gate-long-mode-sys.sh` (new, **5 passed / 0 failed**), each probe patching the corpus
stub's own immediates (`tests/patch-image.py`, which requires each pattern to occur exactly once):

| rule | probe | verdict |
|---|---|---|
| **1 GiB page** | PDPT[0] → `0x83` (PS, frame 0): the whole first GiB becomes one page | the case runs **CLEAN** (a fault or a named stop fails the step) |
| **canonicality** | the body becomes `mov rax, 0x0000800000000000; mov rax, [rax]` | **faults** (`#GP`) |
| **canonicality, able-to-fail** | the same shape with `0x100000` | runs **clean** |
| **FS-base MSR** | the prologue becomes `mov ecx,0xC0000100; mov eax,0x12345678; xor edx,edx; wrmsr` | the STATE tail reports the FS base **`0x12345678`** |
| **baseline** | the unmutated image | runs clean (the probes are not measuring a broken machine) |

**THE PROBES WERE NOT VACUOUS BY ACCIDENT — two were, and were fixed by measurement:** the first
canonicality probe used a **`moffs64`** address, and a moffs above 4 GiB hits the port's own **moffs
bound** before the walk, so it was green against the canonicality mutant; the address is now loaded
into a **register**. And the first 1 GiB probe asserted only "a document was printed", which a
**faulting** run also does; it now requires **no signal**.

**Asymmetry MEASURED for the two walk rules** (mutant → probe red → restored → green): with the
canonicality check disabled the non-canonical probe fails; with the 1 GiB arm disabled the 1 GiB
probe fails. *(Recorded honestly: the first versions of both probes passed against their mutants —
the lane's recurring lesson, twice in one slice.)*

## 3. NAMED GAPS — what this slice did NOT land, and why

Each is a **gap**, not a promise, and each names its missing instrument:

1. **SYSCALL (0F 05) / SYSRET (0F 07)**: the MSRs are modelled (§1.3) but the **encodings are not
   implemented** — with `REX.W` they stop by name. What would close it: the bodies plus a probe
   image that sets `STAR`/`LSTAR`/`FMASK`, executes SYSCALL, and asserts RIP/CS/RFLAGS in the STATE
   tail. The plan's §2.2 calls this "the guest's userspace as the decisive proof", which is S12's.
2. **SWAPGS (0F 01 /5)**: `kernel_gs_base` exists, the instruction does not. **The reason is
   structural**: `0F 01 /5` has **no entry in v86's table**, so the generated dispatch has no arm
   for it — landing it needs an authored entry (the overlay's mechanism works for 0F second bytes,
   not for a `fixed_g` sub-op the 32-bit table does not carry), i.e. an emitter extension.
3. **The 64-bit GDT/IDT/TSS/IST and the 64-bit interrupt frame**: the descriptors are still decoded
   at their 32-bit shape; `call_interrupt_vector` still builds a 32-bit frame. This is the largest
   remaining piece and it is what a real kernel needs first — it is the **first item of S12's work**,
   not a silently skipped rule.
4. **The long-mode TLB's page-flag split**: the 64-bit-keyed TLB clears whole on a non-global flush
   (S5's stated simplification) — a rule with no probe.
5. **`#PF` error-code bits that only exist at 4 levels** (the I/D and PK bits): unchanged.
6. **The register-source BT family** (S9 §5's named gap, with the settled rule: **signed,
   byte-granular, NOT masked**) is still not landed and still has no probe.
