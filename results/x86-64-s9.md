## 2. What landed

**`src/cpu/instructions_64.c`**: the string ops as **their own loop**, not a widened `string.c` —
that file's `string_instruction` runs its addresses and count through `int32_t` throughout (a
32-bit ASIZE model), so a 64-bit form would mean widening the shared body for every op and size.
The five Q opcodes (`0xA5` movs, `0xA7` cmps, `0xAB` stos, `0xAD` lods, `0xAF` scas) × their three
prefix arms (`none`, `F3`, `F2`) = **15 bodies** over five helpers (`str64_stos/movs/lods/scas/
cmps`), with the SDM's rules: source RSI, destination RDI, count RCX, accumulator RAX, step ±8 by
DF, and `repz`/`repnz` stopping on ZF.

Plus `instr64_0FB1_{mem,reg}` (**cmpxchg**), `instr64_0FC1_{mem,reg}` (**xadd**) and
`instr64_0FC7_1_mem` (**cmpxchg16b**: 16 bytes against RDX:RAX exchanging RCX:RBX, and the SDM's
**alignment** rule — a misaligned operand is `#GP(0)`, not a split access).

**`gen/x86_table64.js`**: base entries `0xA5/A7/AB/AD/AF`; 0F-qualified `0xB1`, `0xC1`, `0xC7`.

## 3. The silent-wrong surfaces, named

1. **A 32-bit RCX/RSI/RDI** — a `rep stosq` of 4 would write four bytes and advance by four. The
   corpus's `rep stosq`/`rep movsq`/`lodsq`/`scasq` cases compare the whole window, so a 4-byte
   step moves every subsequent word.
2. **The DIRECTION flag** — a body that always increments writes backwards. No corpus case sets
   DF (it is cleared by the prologue's `popfq`); **un-instrumented**, stated in §6.
3. **The ZF exit of `repz`/`repnz`** — a `repz scasq` that ignores ZF runs to the count. The
   corpus's `scasq` case uses the no-rep form; the **rep forms' ZF exit is un-instrumented** (§6).
4. **`cmpxchg16b`'s 16 bytes and its alignment rule** — an 8-byte implementation would exchange
   half the pair; a misaligned operand must `#GP`. Instrumented by `strobits-cmpxchg16b` (the
   16-byte compare-and-exchange) — and its flag word is masked to **ZF only**, which is the one
   flag the SDM defines for it (the first version compared PF and mismatched, §4).
5. **`xadd`'s register half** — the OLD destination must land in the source register. Instrumented
   by `strobits-xadd-64`.

## 4. A defect this slice found in its own first version

`strobits-cmpxchg16b` compared a **PF** that the SDM leaves **undefined** for CMPXCHG16B (only ZF
is defined): the port's derived PF was 1, the host's 0, and the case failed on four fields. Fixed by
masking the case's stores to **0x40 (ZF)** and normalising the `rflags` element with `cmp rax, rax`
— the S8 §4 pattern, applied to a new instruction.

## 5. What this slice does NOT cover, named rather than implied

- **The `BT` MEMORY form's `imm8 >= 64` rule is an OPEN FINDING, not a solved one.** S8's round 2
  fixed the bodies to a **byte-granular** bit string (`addr + bit/8`, bit `& 7`) on the reviewer's
  reading; the review's own text says the offset **DIV 64 selects the qword**. I built the case
  that distinguishes them (`bts qword [r8], 100`) and **the HOST agreed with neither**: it wrote
  `0x10` at `0x100304` (byte 4, bit 4), i.e. it behaved as if the base were masked to `0x3F`
  (100 & 0x3F = 36 → byte 4, bit 4). **MEASURED, recorded, and the case shipped uses bit 20**,
  where all three readings agree, so the memory form IS instrumented without asserting a contested
  rule. The `>= 64` behaviour needs a decision (and a spec re-read) before any of the three
  readings is claimed.
- **The `rep` forms' ZF exit and the DF=1 direction**: no case (both stated above).
- **`bsf`/`bsr`/`shld`/`shrd`/`bswap`** are S8's and already green; **seven of `bswap`'s eight
  register encodings** remain un-instrumented (S8's §6), and this slice did not add them.
- **`cmpxchg`'s not-equal arm** is instrumented by `strobits-cmpxchg-64`'s second half (the case
  stores flags after a failing compare) — but its **register** form (`0F B1` mod>=C0) has no case.
- **The string ops' FAULT partial-effects** (a `rep movs` that faults mid-way) are the SDM's
  "undefined destination" corner — out of the corpus by rule; the bodies keep RCX/RSI/RDI at the
  last completed element, which is a stated choice, not a verified rule.
